INSTALLATION GITHUB — VERSION PREMIUM

1. Décompressez cette archive.
2. Ouvrez le dossier obtenu.
3. Sélectionnez tout son contenu avec Ctrl + A.
4. Dans GitHub : Add file > Upload files.
5. Glissez tous les fichiers.
6. Commit changes.

Important :
- index.html doit être à la racine ;
- le dossier assets doit être à côté de index.html ;
- remplacez les anciens fichiers du dépôt lorsque GitHub le demande.

GitHub Pages :
Settings > Pages > Deploy from a branch > main > /(root)
