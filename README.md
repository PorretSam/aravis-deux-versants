ARAVIS DEUX VERSANTS — CODE SOURCE FIDÈLE AU MODÈLE VALIDÉ

Contenu :
- index.html : page d’accueil avec la même présentation générale que la maquette
- pages secondaires prêtes à personnaliser
- assets/css/styles.css : tout le design
- assets/js/app.js : menu mobile + lecture vidéo
- assets/img/ : logo et illustrations SVG modifiables

Conseils :
1. Ouvrez index.html si vous voulez modifier les grands textes de l’accueil.
2. Ouvrez assets/css/styles.css pour ajuster couleurs, tailles, espacements.
3. Cherchez “ARAVIS” dans les fichiers HTML si vous voulez renommer le site.
4. Remplacez les SVG par vos propres photos dans assets/img/ si souhaité.

Publication GitHub Pages :
- décompressez le ZIP
- envoyez tout le contenu dans votre dépôt GitHub
- activez Settings > Pages > Deploy from a branch > main > /(root)

2. Vol de Beauregard — Hiver
   Identifiant YouTube : z4XrgOrd42s

Pour ajouter une troisième vidéo :
- ouvrez index.html ;
- copiez l’un des éléments <button class="video-button"> ;
- changez data-video-id, data-video-url, data-video-title et le texte du bouton.

Le clic sur un bouton remplace automatiquement la vidéo, le titre,
la description et le lien vers YouTube.

FORMULAIRES E-MAIL
------------------
Les formulaires Moniteur de ski et Aravis Parapente utilisent FormSubmit :

https://formsubmit.co/samuelporret@gmail.com

Après la mise en ligne :
1. Envoyez un premier formulaire de test.
2. FormSubmit enverra un message d'activation à samuelporret@gmail.com.
3. Ouvrez ce message et cliquez sur le lien de confirmation.
4. Faites un second test : les demandes seront ensuite transférées par e-mail.

Le service ne fonctionne pas correctement lorsque les pages sont ouvertes
directement comme fichiers locaux. Testez depuis GitHub Pages.
